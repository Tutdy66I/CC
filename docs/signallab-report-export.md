# SignalLab v0.4 实验报告导出

在 BPSK、BER 扫描或 QPSK 实验下方使用“导出 HTML 报告”或“导出 Markdown 报告”。无需登录或额外模型调用；未配置 AI 也能导出实验结果。

HTML 报告包含内嵌 SVG 图片与样式，可离线打开。用浏览器的“打印 → 另存为 PDF”生成 PDF；应用本身不直接下载 PDF。Markdown 保留同样的参数、结果和图像数据 URI，图像显示取决于阅读器支持。

## 报告内容

- 应用版本、实验类型、Asia/Hong_Kong 时区生成时间。
- 参数、随机种子、实测结果和有噪声条件下的理论 BER。
- BPSK/QPSK 的完整输入与恢复比特、前32比特/前16符号的采样明细；波形保留前32比特，星座图保留前500符号，与页面相同。
- BER 原始运行参数、完成状态、已完成点的理论与实测 BER、逐点区间及类型。修改输入框不会改变已有运行参数。运行中、取消与失败报告均明确标注未完成，不推断缺失数据。
- 无噪声时明确说明 Eb/N0 不参与计算；零误码不代表真实 BER 为零。
- 可选附带该实验当前保留的已完成 AI 问答及各问题当时快照。默认关闭；不包含正在等待的问答。AI 输出与实测结果分节。

导出在点击时同步捕获数据和图表，生成独立文件。后续调参或清空对话不改变已下载文件。图片固化当前样式，文字在白底报告中使用深色；HTML/Markdown 文本均转义，HTML 同时限制外部资源和脚本。没有上传、云端保存或自动调用模型。

## 验证（2026-10-20）

- `npm.cmd test`：59 项通过（报告格式化7项）；包含 HTML/Markdown 转义、嵌图、时区、完整比特与采样表、无噪声、取消扫描的区间与种子及不可变字符串。
- `npm.cmd run build`、`npm.cmd run lint`：通过；代码审查未发现需修复的问题。
- 浏览器真实下载 BPSK HTML/Markdown、QPSK HTML、完整 BER HTML；检查3张波形、1张星座图、8点统计数据和零误码上限。
- 离线以本地文件打开 BPSK HTML，3张 SVG 图片成功解码；检查屏幕长图及打印媒体，无横向溢出。390×844 应用界面无页面横向溢出。
- 浏览器验证无效参数与未运行扫描禁用导出；取消扫描后编辑种子，报告仍保留原运行种子；AI 默认排除、勾选包含、旧种子42与当前种子43并存、模型文本中的 HTML 被转义。测试提问使用浏览器替身；导出没有发起新模型请求。
- 尚未验证所有浏览器、Markdown 阅读器、实际打印机或所有分页组合；PDF 由浏览器打印功能生成。
