# SignalLab v0.6 实施计划

基线 9574d3c，2026-10-21。目标：16QAM、三调制 BER 对比、参考辅助 EVM。

## 数学与实现约定

- 新增 Gray 方形 16QAM：四位的前两位控制 I、后两位控制 Q；每轴 00/01/11/10 对应 −3/−1/+1/+3，乘 a=√(2/5)。平均 Es=4、Eb=1；实际短输入的平均能量可能不同，不重新缩放。
- 判决边界 −2a、0、2a，恰好相等归上侧区间；拒绝非二进制、空输入、非四的倍数及非有限采样。
- 沿用现有 Mulberry32/Box–Muller 采样器，一条流依次消费 I、Q，不修改既有算法。
- 均匀星座的精确 Gray 16QAM BER：3/4 Q(d)+1/2 Q(3d)−1/4 Q(5d)，d=√(0.8 Eb/N0)。由每轴 Gray 4-PAM 各误判区间乘 Hamming 距离求和得到；Q 数值近似需对独立参考值验证，不能将高 SNR 的最近邻近似标为低 SNR 精确值。
- EVM RMS=√(Σ|r−s|²/Σ|s|²)，以实际发送采样为参考、全输入统计，显示百分比。无噪声严格为 0；不是判决后重建参考，不作补偿或标准符合性声明。
- BPSK 现有模型仅实轴噪声，其 EVM 与二维 QPSK/16QAM 不可直接当作相同带宽、相同 RF 实现质量指标。

## 分步实施

1. 核心测试先行，新增 qam16、evm 模块，保留旧仿真返回结构和种子行为。
2. 独立三调制比较 Worker，O(1) 工作内存；统一每点比特数、Eb/N0、点种子。64 比特循环依次发送四位字 0000 至 1111，完整周期保证均匀分布。
3. BPSK/QPSK 共用逐位噪声序列，因此对比 BER 完全重合是模型和共用随机数的结果；16QAM 每符号两次噪声采样。每点沿用 seed+index 回绕。
4. 比较曲线显示理论/实测，零误码独立显示，不伪造对数值，不把相关比特的 Wilson 区间当作 16QAM 精确置信区间；首版比较不提供置信带。保留原 BPSK Wilson 扫描功能。
5. 16QAM 星座图、判决表、EVM、性能解释；旧 BPSK/QPSK 增加 EVM。新实验接入报告与助教摘要，扩展教学规则，Pages 保持后端限制。
6. 核心/报告/HTTP 测试、桌面/移动 E2E、类型/Lint/构建、Pages 路径检查；文档和逐阶段提交。当前授权覆盖部署，此次推送 master 会依现有 CI 自动发布，需等远端和线上验证完成。

## 取舍

选择独立比较 Worker，避免改变 v0.5 旧扫描协议和基准。暂不引入同步误差、脉冲成形、均衡、其他 QAM 阶数、真实 RF 标准判定或后端部署。
星座只绘前 500 符号，统计使用全部输入；不将实测 EVM 反推为独立 BER 真值。

参考：MathWorks analytical BER / comm.EVM；最终文档记录定义、理论适用条件与验证限制。
