# SignalLab AI v0.8：引导式实验

采用已确认的“预设实验模板 + AI 参数建议”方案。首批目标为 BPSK/QPSK
BER 对照、16QAM BER/EVM、样本量与种子波动。复用现有 AWGN、对比仿真、
种子派生和固定样本统计，不添加调制方式。

流程：选择目标 → 编辑参数或请求 AI 建议 → 校验 → 用户确认 → Worker
计算 → 保存完成快照 → 用户请求 AI 分析 → 据建议修改参数、再次确认。

- AI 规划只返回受限 JSON；不得改变用户选定目标。非法响应显示错误，不能执行。
- 参数包括每次比特数、基础种子、重复次数和预设 Eb/N0 点。
- 样本量模板比较 N/4 与 N；每组完整覆盖 64 比特星座周期。
- 确认后冻结方案。取消、异常和旧异步响应不能生成完成记录。
- 保存最近五次完成记录至本地浏览器，导出 JSON 包含方案、真实结果、种子规则和分析。
- 理论与实测偏差、EVM、逐点保守区间由程序计算；AI 只解释提供的快照。
- 零误码不表示真实 BER 为零；配对噪声使 BPSK/QPSK BER 重合；
  标准差不是置信区间，区间不是整条曲线的同时置信带。
- 静态 Pages 使用模板运行与导出；AI 需要已有 Node 模型后端。
- 模型请求失败保留结果，支持取消与重试；不用真实密钥或付费调用进行测试。

实施与验收：先补核心与浏览器用例，确认缺失行为；实现有界参数协议、
Worker、独立引导区块和 AI 服务端规则。验证复现、参数边界、冻结快照、
取消/恢复、规划与分析隔离、存储/导出，以及静态降级。运行测试、类型检查、
lint、构建与浏览器回归，格式化并提交；不纳入用户已有未提交文件。
