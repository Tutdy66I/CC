# SignalLab AI v0.8：AI 引导式实验

v0.8 将现有仿真、多种子统计和 AI 助教接成一个有明确确认步骤的实验流程。
基线为 `0a454a2`；设计与实施范围见 [计划](signallab-v0.8-plan.md)。

## 使用流程

1. 打开 `#/signallab` 顶部的“AI 引导式实验”。选择 BPSK/QPSK BER 对照、
   16QAM BER/EVM 或样本量与种子波动。
2. 核对目标、每次比特数 N、重复次数、基础种子与 Eb/N0 点。
   可直接使用模板，也可点击“AI 建议参数”。AI 建议必须通过参数白名单校验，
   不能改变已选目标；无效响应不覆盖方案，也不运行仿真。
3. 点击“确认方案并运行”。Worker 冻结并执行该方案，界面显示进度，支持取消。
   只有完整运行才生成完成记录；取消和异常都能重新运行。
4. 查看总误码数、总比特数、实测与理论 BER、偏差、样本标准差、逐点区间与 EVM。
5. 点击“AI 分析本次结果”。只发送所选完成记录，分析随该记录保存；
   编辑下一轮参数不会改写旧结果。取消或失败保留结果并允许重试。
6. 根据建议修改参数，或“载入此方案再实验”，再次确认后运行。

浏览器本地保存最近五次完成记录，刷新后恢复；导出 JSON 可长期保存方案、
目标、真实数据、逐次种子、统计限制和 AI 分析。记录仅存于当前浏览器来源，
不会上传到云端；请求 AI 分析时会将所选记录发送至配置的模型服务。
浏览器存储被禁用或写满时会显示提示，仍可在本页查看和导出。
本地记录可被用户修改，不作为防篡改审计凭证。

## 计算与复现

- 复用 `simulateComparisonPoint`，不修改原调制、噪声和判决算法。
- N 可选 16384、65536、131072；重复 5、10、20 次。Eb/N0 为
  `[-4,-2,0,2,4,6,8,10,12,14]` 的非空递增子集；种子为 uint32。
- 样本量模板比较 N/4 与 N 的 BPSK，各自完成预定重复次数。
- 第 j 次、第 i 个完整网格点的种子为 `(base+j*10+i) mod 2^32`，
  i/j 从零开始，i 使用完整十点网格索引，选择部分点不会改变种子日程。
- BPSK/QPSK 使用配对逐位噪声，因此实测 BER 完全重合；样本量模板使用
  配对前缀，两组不是独立样本。
- 实测 BER=总误码数/总比特数；偏差=实测 BER−理论 BER。
  样本标准差以重复次数−1 为分母，描述种子波动。
- 完整 64 比特周期作为有界误码比例样本，沿用 v0.7 的逐点 95% Hoeffding
  保守区间；半宽 `sqrt(ln(40)/(2*totalBits/64))`，裁剪到 [0,1]。
- EVM 为各次等长试验 RMS 平方均值的平方根，再乘 100 得到百分比。

## 限制

- GitHub Pages 可运行模板、保存和导出；AI 规划与分析需要配置现有 Node
  后端的 `AI_BASE_URL`、`AI_MODEL`、`AI_API_KEY`。本轮未使用真实模型密钥或付费调用。
- AI 负责提出方案和解释，不提供可执行代码，不直接运行实验。模型分析仍需
  对照表格核验；系统不把模型叙述当作测量值。
- 模型只覆盖理想 AWGN 和硬判决，不代表硬件或真实链路验证。
- 区间假定块间理想噪声独立，PRNG 是近似；逐点区间不是同时置信带，
  低 BER 时可能较宽。零误码不代表真实 BER 为零；区间内包含理论值不构成证明。
- BPSK 只测实轴 EVM，不能直接视为与二维调制相同 RF 条件的对比。
- JSON 导出是本轮新增的完整引导记录格式；原有 HTML/Markdown 图表报告继续保留。
- 用户原有 `.mcp.json` 和 `user-memory.local.md` 不纳入本轮提交。
