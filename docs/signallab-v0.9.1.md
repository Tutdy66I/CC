## 使用

在 `#/signallab` 的“理想载波补偿对照实验”选择 BPSK/QPSK/16QAM、相位或频偏
扫描、固定 Eb/N0、比特数、重复次数和基础种子，确认后运行。每个扫描点同时显示
未补偿与理想补偿的实际误码数、BER、理论 BER、实测−理论偏差、逐点区间、
实测/理论 EVM 及其百分点偏差。两幅星座图共用轴尺度、参考符号及采样位置。

“补偿后−补偿前”是同批样本的配对变化；负数表示该指标下降，不保证每次含噪
试验的 BER 都改善。图使用第一试验最多128个跨帧位置，统计包含全部符号。
修改参数不会改写完成记录，载入历史方案也需再次确认；取消/异常不产生本轮记录。

新实验独立本地保存最近五次，并导出 `SignalLab-compensation-*.json`。旧 v0.8
和 v0.9 历史不迁移、不改写。登录后新实验也不进入云同步队列，不包含在现有
云端应用备份中。保存失败仍可导出内存结果；未知版本、损坏历史及并发存储变化
会提示并保留原始存储。当前没有 JSON 文件导入；本地数据不是审计证据。

## 信道与补偿

```
theta[n] = phi + 2*pi*epsilon*n
r[n] = s[n]*exp(j*theta[n]) + w[n]
corrected[n] = r[n]*exp(-j*theta[n]) = s[n] + w[n]*exp(-j*theta[n])
```

使用真实 phi/epsilon，不包含估计、训练、锁定或跟踪。n 是绝对零起点符号索引，
跨64比特周期不重置。符号采样模型沿用 v0.9，不含过采样、滤波失真或 ISI。
整个含噪接收样本逆旋转，不把噪声删掉，不重新取噪声，也不直接使用干净发送符号
作为补偿输出。圆对称 AWGN 旋转后分布不变，单次实现的噪声能量也保持不变。

`simulateCarrierPoint` 的可选观察器提供同一条真实接收流；未传观察器的旧接口输出
保持一致。调制、Eb=1、Gray 映射、门限边界、Mulberry32/Box–Muller 顺序及种子
规则不变：`(baseSeed+trial*10+snrIndex) mod 2^32`，完整十点网格索引；BPSK Q 流
种子仍为 `seed XOR 0x9e3779b9`。补偿不消耗随机数。

固定种子时，各偏移点的补偿后 EVM 仅有浮点舍入差别，因为旋转保持噪声能量；
补偿后的误码数不要求与另行生成的零偏移噪声实现相同，因为噪声方向发生了旋转。
零偏移时两路是同一接收数据；无噪声时补偿后误码为零、EVM在1e-12容差内接近零。

## 理论参考

未补偿 BER 继续按 v0.9 的有限帧实际符号、逐符号偏移和原判决区域预测。
补偿后使用圆对称 AWGN 下的理想同步 BPSK/QPSK 或 Gray 16QAM 理论；无噪声为零。
理论概率使用既有 erfc 近似，独立参考及跨浏览器比较容差为1e-7。

两侧 EVM 都以原发送参考的实际能量 E=Σ|s[n]|² 归一化，不另行拟合增益或相位。
显示的理论 EVM 是 `sqrt(E[EVM²])`，不是随机 RMS 的期望 `E[EVM]`：

```
sigma² = 1/(2*10^(Eb/N0/10))
ideal EVM reference = sqrt(2*Ns*sigma²/E)
raw EVM reference = sqrt((Σ|s[n]*(exp(j*theta[n])-1)|² + 2*Ns*sigma²)/E)
```

无噪声时去掉噪声项。对完整64比特周期，平均 Es 分别为1/2/4，所以含噪理想参考
依次为 `1/sqrt(k*gamma_b)`，k=1/2/4。BPSK 此处是复数 I/Q EVM，区别于早期实轴 EVM。
频偏下16QAM的参考能量加权按实际符号时间计算，不假定每个相位均匀覆盖星座。

等长试验 EVM 以 RMS 平方均值再开方汇总；种子样本标准差保存在 JSON。
区间沿用完整64比特块的逐点95% Hoeffding 半宽 `sqrt(ln(40)/(2*totalBits/64))`。
允许块均值不同，假设理想噪声块独立，PRNG近似；不是同时置信带，也不是两个
独立样本组的差异检验。零误码上界保持正值，不将区间覆盖解释为证明理论成立。
