## 使用与边界

在 `#/signallab` 的“载波估计与恢复实验”确认方案后运行真实 Web Worker。
支持 BPSK/QPSK/16QAM，显示三路同帧数据的星座、误码数、BER、EVM、估计误差、
展开相位拟合与补偿后残余相位。参数修改不更改完成快照，可载入历史方案后重新运行。
取消、错误、迟到消息不写入本轮记录；启发式警告保留实际估计结果，不回退到真值。

导频位置 `n=mL`，首尾都是导频，`N=(P−1)L+1`，数据符号 `D=N−P`。
L=2..128、P=8..1024，最大允许帧130945符号。默认 L=16、P=128，导频开销约6.30%。
Eb/N0 仍按数据位 Eb=1、每个实轴噪声方差 `1/(2*gamma_b)` 定义；导频不携带数据位。
数据保持64位循环、原Gray映射与门限。导频能量为平均数据符号能量 k=1/2/4，
16QAM使用非数据星座的公开训练符号 `sqrt(2)+j*sqrt(2)`，不伪装成16QAM数据。
显示实际整帧能量与数据参考能量比及含开销的每载荷位能量；不根据开销暗改噪声。

旧 v0.9/v0.9.1 内核、种子规则、UI与存储均保留。新帧沿用原随机发生器及采样次序，
每个发送符号消耗I/Q噪声，BPSK Q 使用异或种子；因插入导频，不宣称其数据噪声与旧帧相等。
单帧使用所填种子，多种子研究继续使用原 `(base+trial*10+snrIndex) mod 2^32`。

## 估计器与独立数学参考

`pilotEstimator.ts` 没有仿真/信道依赖，只接收已知导频与含噪接收导频。
先计算 `z_m=r[n_m]*conj(p_m)/|p_m|²`，展开 `arg(z_m)` 到 y_m；
中心化最小二乘计算 `omegaHat=Σ(n−nbar)(y−ybar)/Σ(n−nbar)²`，
`epsilonHat=omegaHat/(2*pi)`，`phiHat=wrap(ybar−omegaHat*nbar)`。
测试用独立复数三角函数构造观测、独立数组参考和手写判决区域验证，不以生产估计器产生期望值。

无噪声严格无歧义范围 `|epsilon|<1/(2L)`。epsilon 加 q/L 在所有导频处增加整周，
仅用这些导频无法区分；边界不保证恢复。已知复数训练符号消除星座旋转歧义，
初相位仍仅模360°可辨识。频偏误差直接相减，不能模1/L相减后掩盖混叠。
真值只进入信道、理想分支和事后评价，不能用于展开、选择解、纠错或失败回退。

零幅/非法/非有限导频或退化拟合返回结构化失败；估计补偿为null。
残差RMS>0.5rad、相邻增量≥0.9pi、归一化幅度<0.1触发启发式警告。
低SNR可能发生整周跳变，残差或幅度无法检测全部错误，诊断通过不是正确锁定证明。
无信道噪声时也保留超范围混叠样例。这里没有PLL、连续跟踪、衰落或定时恢复。

## 配对比较与误差关系

只生成一次含噪帧，估计从导频读取观测，三个分支都读取同一数据接收数组：
raw=r，estimated=r*exp(−j*thetaHat)，ideal=r*exp(−j*thetaTrue)。
逆旋转同时作用于信号与噪声，没有重新生成噪声、替换干净发送信号或排除难判样本。
BER分母为kD，EVM为 `sqrt(Σ_data|output−s|²/Σ_data|s|²)`。
理想分支是理想同步参考，不要求每个有限噪声实现都优于估计分支。

补偿后剩余相位为 `delta[n]=thetaTrue[n]−thetaHat[n]`；无噪声时
`EVM²=Σ_data 4|s[n]|²*sin²(delta[n]/2)/Σ_data|s[n]|²`。
频偏误差随索引积累，相位误差造成整体旋转；相位误差、噪声和判决边界共同决定BER。
相位图在数据位置画圆周残差，避免混叠时仅看导频误判为恢复成功。
星座三图共用相同分层抖动预览位置和坐标轴，最多128点；全部数据用于统计。
预览和圆周图不是完整波形，也不能排除预览之间的快速旋转。

## 本地记录、安全与兼容性

`signallab-carrier-estimation-v1` 独立保存最近5次完整快照，可导出JSON。
记录含版本、帧参数、随机规则、实际导频观测、拟合轨迹/诊断、三路数据指标和预览。
解析校验方案、数量、固定映射/能量、导频拟合、误差、BER分母、预览索引和配对逆旋转；
显式投影允许字段，限制文本/列表长度。此为结构/数学校验，不是测量真实性认证。
未知版本、损坏或并发历史保留原文；存储写入失败时结果仍在内存并可导出。
登录后也不进入云上传队列，不改数据库/RLS、配额、注册或AI助教接口。
没有JSON导入或云端迁移。测试使用本地模型替身和合成Supabase响应，不访问付费AI或生产库。
