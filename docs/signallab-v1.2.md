# SignalLab v1.2 平坦衰落与导频信道估计研究

正式固定样本研究于 2026-10-25 香港时间 19:24:42 完成。63 个分组、189 格均达到每格 10,000 帧；独立归档审计通过，源码和实际执行指纹均与计算前冻结的协议一致。以下数字来自完整研究，快速模式结果未用于科学结论。

## 协议、统计单位与完整性

固定参数为帧长 N=1024、seed=42、导频数 P=4/16/64。导频占用帧首 P 个位置，统计 BER 时只计数据；跨 P 的配对比较使用共同数据位置 n≥64。

| 矩阵                      | 范围                                                        | 分组 | 格数 |
| ------------------------- | ----------------------------------------------------------- | ---: | ---: |
| 主矩阵，data Eb/N0        | BPSK/QPSK/16QAM；−4/0/4/8/12/16/20 dB；AWGN/准静态 Rayleigh |   42 |  126 |
| 含导频总能量，total Eb/N0 | QPSK/16QAM；0/8/16 dB；AWGN/准静态 Rayleigh                 |   12 |   36 |
| 模型失配负对照            | 三调制；0/8/16 dB；逐符号独立 Rayleigh                      |    9 |   27 |

归档共有 630,000 个分组帧记录、1,890,000 个 cell-frame，每种方法累计数据位数 4,631,400,000。分组之间及同组的导频布局复用共同随机数；这些累计数量不能作为合并后的独立样本量。每格的独立统计单位是 10,000 个 frame。

单方法 BER 使用逐格 95% Hoeffding 区间，半径为 0.0135810152；同一 frame 的共同数据 BER 差使用配对区间，半径为 0.0271620303。189 格没有同时 95% 覆盖保证。400 次固定种子 frame bootstrap 是近似参考，帧错误率的 Wilson 区间也不用于把衰落位当作独立样本。

本次恢复接续了 `main-16QAM-8-rayleigh-block` 中已落盘的 2,220 帧。最终保留 63,000 份不可变增量 checkpoint、63 个独立压缩分组与一份合并原始归档，无残留临时文件。审计逐组核对冻结方案、F、压缩字节 SHA-256、独立文件与合并归档的解压内容，并经记录解析器重算摘要。

data-eb 分组的 raw/ideal 共同数据指标做了 2,040,000 次逐 frame、逐方法、跨 P 比较，差异数为 0。total-eb 分组使用共同标准随机数，但噪声幅度随 P 改变。

## 理想 CSI、理论 BER 与 LS MSE

独立 Python 参考仅使用标准库：从 Gaussian 判决区间积分 Gray 16QAM BER，再对指数分布信道功率积分；BPSK/QPSK 与 Rayleigh 闭式交叉核对。参考不导入 TypeScript 或项目 PRNG，也不读取仿真测量值。显式提供 Python 后，两项跨语言验证均通过，0 项跳过。

包括 total-eb 内部 SNR 折算在内的 189 格理论值均通过独立参考核对。最大绝对数值差为 1.9428903×10⁻¹⁶，最大相对差为 2.6390619×10⁻¹⁴；使用的相对容差为 2×10⁻¹⁰、绝对容差下限为 2×10⁻²⁵。

189/189 格 ideal BER 的逐格 frame Hoeffding 区间包含独立理论值；实测 BER 与理论的最大绝对偏差为 0.001095143。这说明这批固定样本与相干理想 CSI 理论相容。

下面是 data Eb/N0=8 dB、准静态 Rayleigh、P=16 的全数据位置 BER：

| 调制  |   独立理论 |        raw |      ideal |         LS |
| ----- | ---------: | ---------: | ---------: | ---------: |
| BPSK  | 0.03545907 | 0.49840000 | 0.03641657 | 0.03864415 |
| QPSK  | 0.03545907 | 0.49616374 | 0.03635863 | 0.03846895 |
| 16QAM | 0.06198768 | 0.44412525 | 0.06297760 | 0.06568646 |

AWGN/准静态模型的导频 LS 理论 MSE 为 N0/(P·Ep)，其中 BPSK/QPSK/16QAM 的 Ep 分别为 1/2/4。对应 162 格的实测/独立理论 MSE 比值范围为 0.984550475–0.999022988。因为各格复用噪声流，这些比值不是 162 次独立验证。

例如 QPSK、8 dB、准静态 Rayleigh：

|   P |    理论 MSE |    实测 MSE |   实测/理论 |
| --: | ----------: | ----------: | ----------: |
|   4 | 0.019811165 | 0.019791809 | 0.999022988 |
|  16 | 0.004952791 | 0.004880857 | 0.985476065 |
|  64 | 0.001238198 | 0.001219068 | 0.984550475 |

本批样本呈现增加导频降低估计误差、LS BER 接近 ideal 的趋势。小 BER 差异的解释仍以配对区间为准。例如 QPSK、8 dB、P=16 的 LS−ideal 共同数据 BER 差为 0.002109271，主区间为 [−0.02505276, 0.02927130]；近似 bootstrap 区间较窄，不能替代主区间。

## 逐符号 iid Rayleigh 的失配负结果

在每个数据符号独立变化的信道上，用前缀导频得到的单一常数估计不能跟踪数据位置的信道。其理论数据位置 MSE 为 1+(1+N0/Ep)/P；增加 P 后仍保留约 1 的误差底限。27 格实测/独立理论 MSE 比值为 0.998835512–1.000132470。

下面是 data Eb/N0=16 dB、P=64 的全数据位置结果：

| 调制  |    理论 MSE |    实测 MSE |    raw BER |  ideal BER |     LS BER |
| ----- | ----------: | ----------: | ---------: | ---------: | ---------: |
| BPSK  | 1.016017482 | 1.016152074 | 0.49984833 | 0.00617813 | 0.50038500 |
| QPSK  | 1.015821241 | 1.015936165 | 0.49987578 | 0.00617688 | 0.50022802 |
| 16QAM | 1.015723121 | 1.015843451 | 0.44286685 | 0.01197466 | 0.48604182 |

27 格 LS−ideal 共同数据 BER 差的逐格主区间下界均为正，最小下界为 0.247040027。BPSK/QPSK 的 LS BER 约为 0.5；16QAM 保留不同幅度判决的行为，不能将三调制统一描述为 0.5。该负对照支持“单一恒定估计与 iid 数据信道失配”的结论。

## 导频开销与 EVM 长尾

N=1024 时，P=4/16/64 的导频占比分别为 0.390625%/1.5625%/6.25%。固定 total Eb/N0 时，N0=[N/(N−P)]/gamma_total，内部 data Eb/N0 相应降低 0.01699785/0.06839425/0.28028724 dB。

增加 P 同时改变估计误差、有效载荷和总能量预算。例如 8 dB、准静态 Rayleigh 下的 LS 共同数据 BER：

| 调制/能量基准   |        P=4 |       P=16 |       P=64 |
| --------------- | ---------: | ---------: | ---------: |
| QPSK，data-eb   | 0.04427688 | 0.03846557 | 0.03689661 |
| QPSK，total-eb  | 0.04442505 | 0.03901010 | 0.03903448 |
| 16QAM，data-eb  | 0.07333961 | 0.06567951 | 0.06366154 |
| 16QAM，total-eb | 0.07355474 | 0.06648469 | 0.06692422 |

total-eb 下 P64−P16 的配对差，QPSK 为 0.000024375，区间 [−0.02713766, 0.02718641]；16QAM 为 0.000439531，区间 [−0.02672250, 0.02760156]。这些小差异未确立某个 P 的总体最优性；它们展示了需要同时核对开销与估计误差的原因。

EVM 使用实际数据参考能量，不拟合增益或相位。未截断 Rayleigh oracle ZF 的总体均方 EVM 发散，因此本研究保留有限样本的 frame 分位数、最大值和 pooled RMS。下面是 QPSK、8 dB、P=16、data-eb、准静态 Rayleigh：

| 方法  | frame 中位数 |        P90 |        P99 |       最大值 | pooled RMS |
| ----- | -----------: | ---------: | ---------: | -----------: | ---------: |
| ideal |   0.34010849 | 0.88505430 | 2.90325304 |  80.31727980 | 1.22760330 |
| LS    |   0.34860506 | 0.90053645 | 2.90665638 | 121.08974717 | 1.51456297 |

有限样本 pooled RMS 也可能与 BER 排序不同。例如相同条件下的 16QAM，LS pooled RMS=0.68317789，ideal=0.86803215，而 LS BER=0.06568646、ideal=0.06297760。应结合 BER、分位数、深衰落与失效指标解释，不能据单个 pooled RMS 推断总体均方稳定性或方法排序。

直接扫描所有原始 frame 的 failure 字符串后，raw/ideal/LS 均为 0；每种方法的 1,890,000 个 cell-frame 中，空 BER 和空 EVM 也均为 0。这描述本轮固定样本。显式 zero-CSI/overflow 边界另由单元测试验证；本批零失败不构成所有参数下的可靠性保证。
