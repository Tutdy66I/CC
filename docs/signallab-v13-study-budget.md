# OFDM comb 正式研究统计与资源预算 v1

2026-10-26 用户选择平衡精度：主BER配对差的绝对半宽±0.02（2个百分点）。本文件与 [机器协议](signallab-v13-study-budget.json) 固定统计和资源预算；正式研究尚未执行。机器协议摘要SHA-256：`e9654ff6b2dcd4e733afccc543af3bc99fdc03431a19e13399d637389b0ddaf4`。

## 研究范围

仅QPSK，单位酉N128、CP16、四个数据符号及一个全训练符号。活动载波±1..±48；公开QPSK训练和comb导频的Ep=Es=2，noiseEnabled=true，随机协议为`signallab-ofdm-rng-v1`。信道为AWGN及默认[0,1,3,7]时延/PDP的块静态Rayleigh；CP充分，不做每帧信道归一化。SNR为[0,8,16,24] dB，分别使用data Eb与包含训练/导频/CP的expected total Eb。

P4=[-48,-16,16,48]；P8=[-48,-34,-21,-7,7,21,34,48]。共同数据集合为活动载波去掉两布局导频并集，共86载波；每帧共同信息位688。三种CSI共用含全训练及comb的物理帧，不将comb描述为已去掉全训练开销。

两个主比较均使用共同位置的完整帧BER：

1. 布局P8的comb-ZF减同布局全训练-ZF。
2. 布局P4的comb-ZF减布局P8的comb-ZF。

2信道 × 4SNR × 2能量口径 × 2主比较，共 **M=32** 个预先指定的假设。同CSI的ZF/MMSE硬判决恒等只作确定性检查；其他指标/比较不追加未经校正的主结论。

## 帧数与同时区间

每个完整独立trial向量产生各条件下的配对观测；同trial的载波、比特、符号、布局和能量口径相关。对每个主比较，帧差D∈[-1,1]。在独立帧模型下使用双侧Hoeffding和Bonferroni：

`P(any |mean(D)-E(D)| >= ε) <= 2*M*exp(-F*ε²/2)`。

取family alpha=0.05、ε=0.02，最小F为35,774，固定 **F=36,000**，同时统计半宽 `sqrt(2*ln(2*M/alpha)/F)=0.0199368661`。不要求各假设彼此独立。这里按[Hoeffding原始论文](https://doi.org/10.1080/01621459.1963.10500830)的有界独立和界与union bound作本项目推导。

擦除/数值失效不删除：逐帧误码率保留下界errors/B和上界(errors+erased)/B，再构造配对差的上下界及全帧区间。有未知误码时区间可能宽于±0.02，必须报告精度未达成。EVM/深衰落ZF MSE可能无有限总体均方，不套用有界BER区间；保留分位数、失败分母及描述性pooled值。

## 分批、种子与资源

每批80帧、batchId=0..449；seed=2026102603+batchId，localIndex=0..79，全局frameId=80*batchId+localIndex。两个能量口径使用相同seed/index以配对；每个trial的载荷、抽头和标准噪声遵循生产角色域。36,000个不同seed/index对才是帧分母，不把1,152,000个物理cell-frame当独立样本。工程预检种子3026102603不在正式范围，不纳入推断。

两个能量口径共900批；每批1280 cell-frame、46,612,480 work-unit，仍在当前1500/50M预算内；每个紧凑JSON≤8 MiB，因此原始记录硬上限900×8 MiB=7.03125 GiB。保留原始文件和一份完整备份，连同manifest、checkpoint、日志与临时文件的磁盘总上限16 GiB；启动时至少20 GiB可用。

本机两个80帧预检批次（非正式研究）：data/total约3.15/2.49秒，4,901,448/4,914,933 bytes，逐文件生成及导入完整性检查通过；Node OS峰值约297.11 MiB。线性估计正式计算/校验约42.29分钟、原始约4.11 GiB；1.5倍时间及10分钟归档预留约73.43分钟。**固定累计活动时间预算2小时，Node进程OS峰值预算512 MiB**。这是当前机器的预测，不是跨机器保证。

时间、内存或磁盘上限触发时只保存可审计前缀，不发布固定样本结果。禁止按误码数、显著性或当前区间提前停止；不能重启重置累计预算。增加时间/资源须有明确的预算修订记录，统计精度、固定F与既有原始文件不能被追溯改写。

## 执行条件

`npm run plan:ofdm-study` 只生成预算；`npm run plan:ofdm-study -- --preflight` 仅执行两个固定80帧工程预检。工具没有正式研究执行入口。

正式运行前须完成并验证流式编排、SHA链/索引/完整前缀的独立审计、执行源码和运行时冻结，再单独授权启动。执行须符合预算指定的种子与条件顺序；不能把450个批次各自的80帧区间当作36,000帧主结论。

BPSK/16QAM、CP不足、其他PDP/时延扩展、其他布局的正式推断另立协议和预算。现有独立参考及工程回归继续覆盖这些边界，但不宣称达到本研究的同时精度。
