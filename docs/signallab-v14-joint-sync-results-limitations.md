# SignalLab AI v1.4：OFDM 联合同步研究结果与限制说明

本文件是已封存研究的后续说明，不修改原始研究结果、冻结协议或审计记录。

## 研究范围

本说明补充 SignalLab AI v1.4 OFDM 载波频偏（CFO）与符号定时偏移（STO）联合同步研究的结果与解释边界。研究基线为提交 `a6bdc290cfc67def6967a945a1548cc79a0f1487`，研究封存标签为 [research-v1.4-ofdm-20261029](https://github.com/Tutdy66I/CC/tree/research-v1.4-ofdm-20261029)。冻结协议 SHA-256 为 `838c09680a471a05c96b79fee70fe3cdb447f9af1894e4c698b069234449c6b6`。

实验使用 FFT 长度 128、循环前缀长度 16、QPSK、归一化 CFO 0.25 和整数 STO 8。四个场景为 AWGN 和固定三径信道分别在 0 dB、8 dB 的数据位 Eb/N0。每场景 25,376 帧，共 101,504 帧、5,076 个提交块。

## 接收分支与结果

同一场景中的三个分支处理同一帧接收观测：

- **未同步**：不进行 CFO/STO 估计或补偿，按名义窗口接收。
- **估计同步**：根据接收观测和公开训练信息估计并补偿 CFO、选择定时窗口；同步失败按擦除记录。
- **理想同步**：使用仿真 CFO/STO 真值进行补偿和窗口选择，作为辅助参考。该分支仍使用训练序列估计信道，并非使用信道真值的理论最优接收机。

## 统计方法与预检重叠

四项主比较使用逐帧配对 BER 差，并以 Hoeffding–Bonferroni 方法构造同时 95% 候选区间。对每场景 25,376 帧、四项双侧比较，统计半径为：

`sqrt(2 × ln(2 × 4 / 0.05) / 25376) ≈ 0.0199999484`。

区间的覆盖解释依赖帧差有界和帧间独立等假设。实验使用固定种子和确定性伪随机流，帧与随机用途采用不同的派生域；这些安排有利于复现，但不同派生状态不能严格证明统计独立。四场景共用相应批次种子和帧索引，比较之间可能相关；Bonferroni 校正不要求四项比较彼此独立。

**工程预检与正式研究存在样本重叠。** 三次工程预检各 100 帧，与正式研究的固定三径、8 dB 场景中三个对应批次的前 100 帧完全相同，共 300 个不同帧对象，约占该场景 25,376 帧的 1.18%。正式运行重新生成这些帧，正式汇总中每帧只计一次；但这些帧不能被称为此前完全未出现过的独立留出样本。由于四场景共享随机域，相应场景也共享部分随机输入。

同一协议哈希出现在工程预检和正式研究清单中。最初三次预检产生于相关工具的首次 Git 提交之前；本地清单时间不能独立证明公开、不可更改的事前注册。现有审查没有发现依据预检结果修改四项主比较或样本量的证据，也不能仅凭现存材料排除所有未留痕的结果驱动选择。预检重叠本身不自动使已固定方案下的区间失效，但应限制对独立盲测和事前注册程度的表述。

## 解释边界

上述结果支持的结论是：在本研究的固定仿真参数、信道和统计假设下，所实现的估计同步分支相较未同步分支表现出较低的配对 BER。不能据此断言估计同步在所有频偏、定时偏移、信道、信噪比或其他同步算法下都会改善 BER。

本次正式研究同时施加 CFO 和 STO，没有在统计设计中将两者影响单独分离；结果不能归因于其中某一项。已有的单项工程验证也不能替代这种独立统计比较。固定三径抽头总能量约为 0.7125，AWGN 场景为单位单径，且使用发送端 data-Eb 口径；因此跨场景 BER 差不能简单解释为多径的单独影响。

本研究是受控仿真，不代表真实无线硬件性能；它没有覆盖实际射频器件误差、时变信道或真实设备接收链，也没有验证其他参数组合或未经测试的同步算法。原始研究记录保留逐帧误码数和擦除数，但没有保存逐位收发判决或完整 IQ 波形，独立审计可以重算汇总和区间，不能仅凭记录逐位重算误码或重放波形。
