# SignalLab v1.4：OFDM CFO、STO 与联合同步

状态：工程实现与确定性验证；不代表正式统计研究结论。研究封存基线为 `5f98b4f1a378fdcc2b059e0a67bbe905345e0e0f`。同步实验使用独立引擎、Worker、随机域和本地 IndexedDB，不加入云同步或旧 OFDM 历史。

## 波形与接收机

- N=128，CP=0…32，QPSK，活动载波 ±1…±48。每帧先发送四段相同的 64 采样公开前导，再发送一个全带训练 OFDM 符号和四个数据符号。前导的 64 采样使用固定 `hash32-v1` 公开序列，脚本 `ofdm-sync-estimation-reference.py` 中有独立定义和向量；该序列没有更短循环周期。
- 固定三径时延 `[0,3,7]`、增益 `[0.8+0.1j,0.2−0.1j,0.1+0.05j]`；AWGN 为 `h[0]=1`。引擎允许最多四个时延不超过 15 的排序抽头，页面提供上述两种信道。信道在一帧内静态，不做逐帧功率归一化。
- 相对名义捕获起点的注入 STO 为整数 `−16…16`。发送波形在完整连续时间上与因果 FIR 卷积，按全局采样索引乘 `exp(j*(phi+2*pi*epsilon*n/128))`，再加复数 AWGN；保护区与卷积尾部均生成噪声。CP 不足时始终保留真正的跨符号干扰。
- 三支共用同一个 noisy capture。未同步分支使用名义 FFT 窗口；理想同步分支使用真实 CFO、相位和 STO；估计分支的输入仅为 noisy capture 与公开 CP/前导，不能访问上述真值或载荷。每支使用自身接收训练符号估计有效信道，再执行 ZF 与 QPSK 判决。理想同步并不消除 CP 不足造成的 ISI。
- 估计 CFO 使用两个相隔 64 的重复区间的复相关，输出 `epsilon_hat=128*arg(P)/(2*pi*64)`，主值为 `[-1,1)`；仅凭该相关无法识别相距 2 的别名。相关能量过低或归一化相干度低于 0.1 返回失败；该阈值是工程规则，尚未经统计校准。
- 用估计 CFO 旋转整个捕获后，在公开的名义训练 useful 起点附近搜索归一化相关：从名义位置 −16 至 +31，最大分数的最早点胜出，然后提前 `min(7,CP)` 个采样作为 FFT 起点。得分低于 0.1 返回失败。该规则可能在低 SNR、多径或 CP 不足时误锁；不以仿真真值选择候选。选择窗口与信道时延是否相容仅在事后用真值评价。
- 若非零抽头范围为 `[l_min,l_max]`、选窗误差为 `delta`，无跨符号干扰条件为 `l_max−CP <= delta <= l_min`。安全窗口内的有效信道含 `exp(j*2*pi*k*delta/N)` 相位斜率。CFO 未补偿或窗口不安全时不使用理想对角信道公式作为仿真结果。

随机版本 `signallab-ofdm-sync-joint-rng-v1` 以 seed、frame、role、slot 派生 SHA-256 小端状态和 xoshiro128\*\*，虚拟数据按每标准 bin 固定消耗四位，capture 噪声独立分域。相同帧的三支完全配对。`data-eb` 以数据 Eb=1 设定 N0；`total-eb` 使用包括前导、训练和 CP 的预期发送能量。每帧共有 768 数据位。捕获失败的估计分支保留全部擦除位，界面报告误码/总位及含擦除的 BER 下界、上界；成功帧的定时安全统计单列，不把未捕获帧删除。

完成记录 `signallab-ofdm-joint-record-v1` 含冻结方案、协议哈希、源码和运行时指纹、完整帧与完整性哈希，仅保留最新一条于 `signallab-ofdm-joint-v14` IndexedDB。写入以 revision 比较保护并发修改，损坏数据不覆盖；用户可导出 JSON。取消计算不保存不完整记录；开始完整结果的保存后不再提供取消。此阶段没有检查点恢复或 JSON 导入。

## 可重复验证与限制

`npm run test:ofdm-sync-reference` 运行 Python 标准库直接 DFT、时域 FIR、复杂相关、完整 CFO/STO 多径含噪波形和随机域参考，并检查零能量、主值别名、短 CP、多径、STO 边界、记录校验及完整前缀。`npm run test:ofdm-sync-edge` 使用本机 Microsoft Edge 测试三分支运行、取消、本地恢复及工程性能。已有 v1.3 源码、随机协议及云同步实现未修改。

这些固定向量验证指定模型和边界，不能推出低 SNR 成功率、统计 BER 改善或任意信道下的安全选窗。未实现分数 STO、采样频偏、符号内时变信道、整数频偏解模糊、MIMO/FEC 或真实射频接收。页面最多 1,000 帧，统计研究不能通过页面自动扩容。源代码字节级兼容仍受 [P1 说明](signallab-v14-p1.md) 所述换行和冻结指纹约束。

## 正式研究提案：尚未批准、尚不可运行

预先指定四项主比较：估计同步减未同步的帧 BER，均用 QPSK、N128、CP16、CFO 0.25、STO +8、相位 0、data Eb/N0、噪声开启；四个场景分别为 AWGN/固定三径 × 0/8 dB。每项以完整独立帧为单位，三支使用同帧、同噪声；四场景可共用逻辑种子做配对，但不把场景、载波或比特当作额外独立帧。

针对四个预先固定比较，取 95% 同时置信度、配对 BER 差绝对半宽 0.02，使用 Hoeffding 与 Bonferroni 的保守界，需 `ceil(2*ln(2*4/0.05)/0.02²)=25,376` 个独立帧/场景，即 **101,504 场景帧**。擦除给出配对下/上界，实际区间可能比目标更宽；区间包含零不等于等效。固定样本完成前不宣布正式区间，也不按结果或误码数提前停止。

建议离线工具按每场景 25 个 1,000 帧批次加一个 376 帧批次执行，每批使用不同的预先冻结 seed 和局部帧号；四场景共享对应 seed/帧号。必须先实现并验证独立版本化的流式编排、原始数据保护、失败统计、断点和审计，不能把当前页面的 1,000 帧上限当作正式研究能力。

拟议资源上限：累计活动时间 60 分钟、受控数值进程峰值 512 MiB、总磁盘 4 GiB、启动前至少 8 GiB 空闲，停止时只保存可核对前缀。正式启动前，需在目标机器上以相同正式源码和运行方式做三次各 100 帧的工程测时，按 `101504 * (三次总秒数/300) * 1.5 + 600 秒` 估计并确认不超过 60 分钟；否则缩小或重新设计研究，不自动削减样本。当前 Edge 一次 100 帧页面测试约 0.362 秒，仅用于说明量级，不能代替目标离线环境的预检。

正式研究必须在工具、样本和资源预算准备妥当后另行获得用户批准；当前未执行。v1.3 原始研究数据的独立异盘备份仍未完成。
