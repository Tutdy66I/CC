# v1.5 numeric feasibility: public fixed-input assessment

Status: exploratory engineering evidence, not a protocol, formal study, proof for all inputs, or authorization. Base: `be0de6db30fce9e3da9fab8b23adcc842301fcd6`. No research RNG, root, protocol identity or study data is used. The 04-numeric fail-closed behavior is untouched.

## Source and actual order

- `src/lib/fft.ts`: radix-2 bit reversal; ascending size, block and butterfly; compute angle, `cos`, `sin`, complex multiply, then subtraction/addition and final `1/sqrt(n)` scaling. This is not an abstract exact DFT with one final rounding.
- `src/lib/multipathChannel.ts`: taps outermost, samples innermost, ordered complex products and additions into zero-initialized output; preserves FIR tail.
- `src/lib/ofdmSync/capture.ts`: continuous FIR, padding, absolute-index CFO phase `(phase/(2*pi)+(cfo/n)*(start+t)) % 1`, `cos`/`sin` rotation, then noise. The remainder and transcendental inputs must be included in any proof.
- `src/lib/ofdmEqualizer.ts`: LS and ZF use the same scaled complex division: `scale=max(abs(hI),abs(hQ))`, then `a`, `b`, `d`, `u`, `v`, then output. Exact zero scale and non-finite coordinates cause failure; LS throws for failed division while ZF returns a null decision and failure category. Neither uses an epsilon.
- `src/lib/ofdmSync/synchronizer.ts`: repeated-preamble correlations and powers are accumulated in source order. `a>1e-24` and `b>1e-24` are strict; coherence `<0.1` fails and equality passes; CFO uses `hypot`, `atan2`, and an angle fold. Timing searches ascending positions and updates only for a strictly larger finite score, so an exact tie retains the earliest. Timing reference/observation energy and score have distinct failure rules.
- `src/lib/ofdmModulation.ts`: finite QPSK coordinates use `>=0` for bit 0; `+0` and `-0` both yield 0. `src/research-v15/receiver.ts` converts useful start to CP start once, then rotates, FFTs, training LS and per-bin ZF; failed ZF erases two bits. Capture/window/invalid-input errors are separate.

## Public tools and exact bounds

Run `python -I -B scripts/v15-numeric-public-selftest.py`, `python -I -B scripts/v15-numeric-public-audit.py`, and `node --test .test-build/tests/v15-numeric-public-boundaries.test.js` after the normal test TypeScript build. The Python audit launches the fixed-input Node script; neither reads protocol files or accepts arbitrary research inputs.

Basic `+`, `-`, `*`, `/` inputs are converted exactly to Python `Fraction`, operated on rationally and converted once to binary64. Expected and observed bytes must match. This relies on CPython's fraction-to-float rounding on the tested platform; the small self-test does not prove it for all inputs. Fixed vectors cover ties, exact results, a normal/subnormal transition and signs, not all IEEE cases.

For sin/cos with `|x|<=1`, 60 and 61 consecutive alternating Taylor partial sums computed as exact rationals bracket the mathematical value: terms decrease for that domain. For sqrt, an integer square root of a scaled exact rational yields certified lower/upper rationals; exact-square bounds coincide. Python converts each bound outward to binary64. If they are identical or adjacent, the Node result must lie within them; otherwise the result is `uncertified`, never silently widened. Signed zero for sin/sqrt is checked separately by bits. The returned adjacent interval proves membership for the tested argument, not correct rounding or a global one-ULP guarantee.

Independent high-precision `log`, `atan2`, `hypot`, general-range sin/cos, propagation through FFT/FIR/LS/ZF/acquisition, and proof of predicate boundaries under propagated uncertainty are **not implemented or certified**. The threshold comparison probes are independent stand-alone expressions, not full acquisition. A separate two-test suite directly calls the existing QPSK/ZF/LS and timing/CFO functions on public boundary inputs. It verifies those particular outcomes, not high-precision equivalence of the full path. No conclusion may be extrapolated from matching BER.

## Measurement and decision

On 2026-11-06 (Hong Kong), Windows 10.0.26200 x64, Node 24.16.0 / V8 13.6.233.17-node.49, CPython 3.9.12: 8 basic vectors, 19 sin/cos/sqrt vectors, 4 sign vectors and 6 threshold vectors passed; zero failed or uncertified among these 37. Three audit self-tests and two direct production boundary tests passed. This is one fixed-input run, not a performance benchmark or proof of total coverage. Example run: Node reported 0.46 ms and ~39.7 MB process RSS at snapshot; Python including Node launch and audit reported 0.064 s and 75,204 bytes Python `tracemalloc` peak. RSS is not a process peak and Python tracing excludes Node and native allocations; these numbers are not execution-engine budgets.

No counterexample to the strict adjacent-float rule was found in this limited set. Its feasibility across the actual complete DSP graph is **undetermined**, not approved. A zero-crossing or threshold-straddling proven interval that cannot select the same branch is `boundary-uncertified`: stop, retain inputs and evidence, and review; do not erase, omit or revise the decision. If further proof finds a real counterexample or intractable cost, separately review alternatives such as a pinned portable correctly rounded math implementation or a versioned, mathematically justified per-operation enclosure. Do not silently choose an epsilon or accept matching BER.

The tested Node executable SHA-256 is `b3094d0b49f9ad602262a9921551737bb97637c05dd357a06ae98188d7290aa3`; Python executable is `deeab3e6be727505a6158f63b7a6c69bea9984cb546357089ede5b817358f233`. These hashes alone do not lock V8/ICU/OpenSSL/DLLs, Python stdlib/math, OS runtime and patches, CPU architecture/features, flags, environment, build tools, compiled output or full source/dependency closure. A future authoritative Node runtime requires an immutable, independently verified complete dependency and environment manifest, clock-independent raw-byte replay, repeat testing and independent backup/recovery. Actual exact version, dependency selection and numeric certification coverage remain approval gates.
