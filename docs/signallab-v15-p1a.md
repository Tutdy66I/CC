# SignalLab v1.5 P1a：单帧同步误差数学核心

本核心只用于确定性工程验证，不是统计研究或新的同步算法。v1.4 的波形、捕获、观测估计器和 FFT/LS/ZF 基础函数只读复用；v1.5 代码不位于 `src/lib`，避免改变现有同步源码指纹的递归输入。

## 约定

- N=128，96 个活动载波，QPSK，公开重复前导、一个全训练符号、四个数据符号，每帧 768 位。`noisePower` 是复噪声的期望功率（等于数据 Eb/N0 口径的 N0），不是接收后信号功率。
- CFO `cfo` 和残余 `e` 以子载波间隔为单位；STO `sto` 和 `delta` 是整数采样数。真实 useful FFT 起点为 `32 + sto + 256 + cp`；干预 FFT 起点加 `delta`。`e>0` 表示校正后残余频偏为正，因此补偿旋转频偏为 `-(cfo-e)`，使用捕获绝对采样索引。
- 干预保留初始相位，不读取相位真值以旋转接收信号；各干预用各自窗口的训练估计有效信道。零残余/零偏移为理想同步参考，独立参考另验证真值相位校正不会改变这些固定向量中的判决。它不使用信道真值，短 CP 干扰仍存在。
- 对非零抽头的最小时延 `min` 和最大时延 `max`，安全窗口为 `max-cp <= delta <= min`。CP 不够时窗口为空。越界的 FFT 窗口抛错，不产生截断结果。
- 四个固定干预为 `(e,delta)`、`(e,0)`、`(0,delta)`、`(0,0)`；交互为第一项减第二、第三项加第四项。每支 BER 的擦除界为 `[errors/bits,(errors+erasedBits)/bits]`；交互界对负系数取相反端点。位数不同或错误计数无效不能当作单帧配对结果。
- `estimateObservation` 仅接收采样与公开 CP，调用现有观测估计器。真值干预在模拟评价层；载荷仅用于事后计数，不进入估计器。该边界是软件接口约束，不是安全沙箱。

## 随机性和参考

仅提供测试域 `signallab-v15-p1a-test-rng-v1`：输入为 `domain|frameId|role|slot`，SHA-256 前 16 字节以小端读取，作为 xoshiro128\*\* 状态；数据和噪声分别分域。接口不接受种子，因此不能使用 v1.4 正式研究种子。该域不得用于未来预检、探索或确认性研究；那些阶段需要另行设计和冻结独立随机域与重复审计。

`scripts/v15-reference.py` 独立实现标准库直接 DFT、FIR、随机派生、噪声、训练估计、判决和采样索引枚举。测试比较四类 CFO/STO、短 CP 的完整波形、噪声、捕获、FFT、误码及交互，并检查窗口边界、零残余理想参考、擦除区间和非法窗口。这些固定向量不能证明所有输入或真实设备表现。
