# SignalLab v1.5 P1b：工程接收机对照

P1b 提供同一帧的未同步、估计同步和真值辅助理想同步，以及 P1a 的 CFO/STO 受控干预。它是测试域中的工程接口，不是正式研究运行器，不提供置信区间或统计显著性结论。

## 信息边界和坐标

模拟层将采样复制到 `makeObservation` 创建的冻结对象。对象对外只有公开 CP；采样副本仅存于接收模块的私有 WeakMap。估计器接受该对象，并只读取副本和 CP；不能接收完整帧、载荷或真值。伪造对象被拒绝。该机制保证模块接口的数据流隔离，不声称 JavaScript 安全沙箱。真值仅用于理想分支、受控干预和事后评价；载荷仅用于事后误码评分。

三支接收同一捕获，使用各自窗口的训练符号执行 LS 和 ZF。估计器使用 v1.4 公开重复前导、相关与定时搜索；不更改其算法。其 `start` 是 useful FFT 起点，而 `receiverFfts` 的参数是 CP 起点，因此恰好减去一次 CP。理想参考校正真实 CFO 并采用真实 STO 窗口，不校正真值相位或使用真实信道。

## 失败与结果

非法参数（包括非有限值、超出接收幅度上限或无效干预窗口）被拒绝。接收采样幅度上限为 `1e12`；工程批次噪声功率上限为 `1e6`，均为数值资源边界。捕获失败与捕获成功后窗口不足分别记为 `capture-failed` 和 `window-failed`，完整保留 768 位全擦除；估计成功但窗口不安全仍保留实际结果。均衡失败逐位擦除。失败原因、估计值和事后真值评价分别记录，未获得窗口时安全状态为 `null`。

每帧保留各支误码、擦除、BER 下界和上界；配对差 `A-B` 的界为 `[L_A-U_B,U_A-L_B]`。四点交互为 `B(e,d)-B(e,0)-B(0,d)+B(0,0)`，负系数使用相反端点。控制点窗口提取失败也保留全擦除；相对完整捕获本身越界的干预是非法实验输入。

`runEngineeringBatch` 只接受 1–16 个不重复的安全整数帧 ID；计算开始前复制帧 ID、配置数值和每个抽头对象，防止调用方后续更改这些数值影响正在进行的批次。抽头是浅拷贝，附加的嵌套对象不会深拷贝。返回的配置、帧列表、结果和汇总没有深度冻结，调用方修改它们可能使返回内容不再一致；汇总不会自动随之重算。每帧结果之外，批次汇总累计三个接收分支和四个干预点的完整分母、误码与擦除，并从累计计数重新计算 BER、配对差和交互界。这些是描述性工程指标，不是置信区间。它使用 P1a 的测试专用随机域，不能用于后续预检、探索性或确认性研究；这些阶段需要另行设计随机域和协议。不会运行大规模扫描或输出统计显著性结论。

## 验证和已知风险

P1b 的独立 Python 参考以标准库直接 DFT、复数相关与窗口搜索验证三分支、误码、捕获失败及窗口失败。额外测试覆盖 CP 起点换算、真值隔离、短捕获、擦除、配对界、批次上限和 P1a 原向量。旧版源码和递归指纹输入保持不变。
