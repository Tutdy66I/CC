# SignalLab AI v1.5 P1c 工程对照

本面板只运行 `engineering-test-only` 随机域中的 1–16 个互不重复的工程帧。结果不是正式研究记录，不上传、不持久化，也不提供显著性结论。

每帧生成一次接收捕获，再在同一捕获上运行 raw、estimated、ideal 和四点受控干预；ideal 只借用同步真值，不使用真实信道或校正真实相位。估计器仍仅接收显式观测和公开参数。每个接收方案保持 768 位分母；失败时展示擦除而不是静默丢弃数据。BER 范围是擦除导致的边界，不是置信区间。四点交互按照 `B(e,d) − B(e,0) − B(0,d) + B(0,0)` 的区间运算计算。

配置在主线程和 Worker 均验证并复制。任务逐帧执行，仅在完整批次通过验证后发布结果；输入无效或意外异常会终止任务，合法接收失败按结果状态报告。取消和卸载会终止 Worker，过期消息不得更新当前任务。CFO 以子载波间隔为单位，定时偏移以采样点为单位；信道抽头能量与噪声功率需结合阅读，不同信道的 BER 不能直接归因于同步误差。

面板不改变旧版研究协议、持久化格式或冻结数学核心。16 帧、消息大小及交互性能的测试仅是工程采样；iPad 实机情况需独立测量。
