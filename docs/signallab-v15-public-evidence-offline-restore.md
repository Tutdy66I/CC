# Synthetic public evidence offline restore prototype

This is a fixed synthetic fixture and offline format experiment. It is not authorized for real study records and does not establish an external backup, authenticate a publisher, or complete `05-evidence`. The synthetic marker is a scope check, not proof of provenance. It is independent of PR #30.

The candidate ZIP contains a canonical ASCII JSON `manifest.json` and eight exact relative payload names: audit stdout, stderr, exit, result and deterministic result; and synthetic input, runtime and source identity. The manifest records each path, length and SHA-256 in fixed order. An independently retained anchor contains the SHA-256 of both the raw manifest bytes and ZIP bytes. The anchor is not inside the ZIP, avoiding a self-reference cycle. SHA-256 alone provides integrity only relative to an already trusted anchor; a digest stored beside an archive is not independently trustworthy. The implementation requires an explicit synthetic-only marker and checks that exit status, observed result, uncertainty classification and deterministic result agree.

Verification checks the external anchor before reading ZIP contents; rejects duplicate names, unlisted or missing entries, absolute/traversal paths, symlinks, excessive uncompressed file lengths, unexpected compression and digest mismatches; and checks the manifest canonical encoding and payload semantics. Restore verifies before creating a new destination and refuses an existing destination or a symlink/junction ancestor. It rereads each restored file and checks exact bytes. These checks are not race-safe against concurrent adversarial filesystem replacement and do not establish origin, confidentiality or a complete runtime closure. Resource exhaustion, ZIP parser vulnerabilities, durable atomic publication, power loss, signatures, trusted timestamping, migration and long-term media integrity need separate design.

The tests create their own temporary synthetic source and backup directories, copy ZIP and anchor, delete only that test-created source directory, and restore to a new test directory. Tests compare each byte and deterministic digest and reject synthetic missing, duplicated, escaped, truncated, altered, symlink and inconsistent data. The operation does not touch existing research data or artifacts. A local copy on the same machine is not an independent failure domain. Genuine independent storage, external anchor custody, retention, periodic integrity verification and restoration on a separate system are **not established**.

Run `python3 -I -B scripts/v15-public-evidence-archive-test.py` from `react-app`. CI saves raw test stdout, stderr, exit status, runtime and source identities and a SHA-256 manifest to a 14-day artifact; that artifact is temporary, not an offsite backup. This prototype must not be used on real evidence until a separately approved format and recovery implementation is reviewed.
