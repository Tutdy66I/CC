# Round-two public evidence preservation candidate

This workflow preserves fixed public diagnostics, not formal research evidence, a protocol, or an approved 04-numeric/05-evidence/06-dependencies implementation. The existing numerical scripts and inputs remain unchanged.

After the existing test build, `v15-round2-evidence-selftest.py` tests malformed JSON, missing/duplicate/changed inputs, altered bounds and classifications, manifest tampering and an audit subprocess failure. `v15-round2-evidence.py` then launches each of the four existing public audits with the current Python executable. A separately stored fixed-input manifest pins the expected inputs, result ordering and trace names. Each audit has its own raw stdout, raw stderr and exit-code JSON; the validator checks expected uncertainties, node counts, synthetic mismatch labeling, finite values, cross-file relationships and recomputed bounds. Unexpected failures, missing inputs, duplicates or unapproved uncertainty fail the step. Failed subprocess output and diagnostics are retained when available.

The artifact also contains `runtime.json`, an explicit source/compiled-code snapshot with SHA-256, `summary.json`, `normalized.json` and a non-self-referential `manifest.json` hashing the other files. The manifest hash is printed in the CI log. `normalized.json` removes timing, memory and runtime metadata recursively so deterministic evidence can be compared across runs; the original output is preserved separately. The output directory must be empty, preventing silent overwrite. The source list is a candidate snapshot, not a verified complete runtime/dependency closure or protection against concurrent replacement.

GitHub Actions uploads a separate `round-two-public-evidence` artifact even when prior steps fail where files are available. Its configured retention is 14 days. A short-lived CI artifact is not an independent long-term backup, and the hash alone does not prove origin or semantic correctness. Formal evidence formats, complete DSP certification, runtime closure and independent backup/recovery remain open.
