Node 使用 Ed25519 的 RFC 8410 DER 封装。SPKI 为十六进制前缀 `302a300506032b6570032100` 加原始 32 字节公钥。PKCS#8 为 `302e020100300506032b657004220420` 加 RFC 公开测试种子。协议封套只使用原始密钥及签名的固定十六进制编码。Go 直接使用对应的原始公钥和签名独立验证。Go 的 JSON 复核限本协议的 ASCII 键和值、非负安全整数、数组、对象及 null。严格检查解码后的重复键和字段类型，重序列化时关闭 HTML 转义，去掉编码器添加的单一 LF，再与原始字节比较；该方法只适用于此子集。

批准执行前，须通过独立可信渠道核对发布者身份与发布摘要，记录 Linux 镜像身份、二进制和源码摘要、Node 内置 OpenSSL 版本及 provider 配置、动态库、Go 工具链和 Python 环境。禁用 npm 依赖、Python extras、源码构建回退及运行时网络取依赖。wheel 以哈希锁定方式离线安装，构建和复核只在此前核验的绝对路径运行。缺失身份、版本不一致或库不支持所需模式时，停止并保留诊断。发行物 SHA-256 绑定所用字节，来源认证仍依赖可信发布渠道，本锁尚不构成运行时依赖闭包。
