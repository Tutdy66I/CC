# SignalLab AI 实验助教

延续当前聊天中的实验问答面板方案。引用的 ChatGPT 聊天仅返回内容占位符，未将其视为已读取的完整规划。

## 范围与实现

- BPSK、QPSK、BER 扫描各有助教入口，显式发送该实验的参数和结果摘要，不发送全部比特或图像。
- 用户可查看本次上下文，使用三种快捷问题或连续追问。历史仅保留当前页面内存；每次提问附带当时快照，避免参数变化后误读旧回答。
- 共用 React 助教组件；实验算法继续本地计算。服务端 `/api/ai-tutor` 在开发与生产共用一个处理器。
- 服务端通过 `AI_BASE_URL`、`AI_MODEL`、`AI_API_KEY` 配置兼容 Chat Completions 的模型。没有默认付费服务或虚假降级回答；缺少配置返回明确错误。
- 固定服务端教学指令要求区分实测、理论与推测，说明零误码和有限样本的限制，优先给实验建议。历史消息只接受 user/assistant 角色。
- 请求限制、超时、取消、重复发送保护和错误提示；输出以纯文本渲染。

## 验证与实施顺序

1. 先写接口测试，覆盖缺配置、输入验证、上下文与历史、安全错误、取消。
2. 实现共享模型服务与 HTTP 处理器，接入开发与生产服务。
3. 实现复用问答组件，接入三个实验数据摘要。
4. 格式化，运行测试、TypeScript/Vite 构建与 ESLint，再提交。

真实供应商调用需要部署者自行配置凭据；本轮使用本地 HTTP 模型替身验证传输链路，不将替身回答作为真实 AI 验证。
