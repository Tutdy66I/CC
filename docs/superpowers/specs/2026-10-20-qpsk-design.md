# SignalLab v0.2：QPSK 与星座图

用户已确认独立 QPSK 实验区方案。本轮新增 QPSK 算法、星座图和页面交互；保留现有 BPSK 波形与 BER 扫描，不接入 AI、不处理主分支整合。

## 模型与界面

- 每个符号包含两个比特，第一位控制 I 轴，第二位控制 Q 轴；0 映射 +1，1 映射 −1。四点顺序为 00=(+1,+1)、01=(+1,−1)、11=(−1,−1)、10=(−1,+1)，相邻点只差一位。
- 使用 Eb=1、Es=2，与原 BPSK 保持相同的每比特能量。I/Q 独立噪声方差均为 `1/(2*10^(EbN0Db/10))`；复用现有固定种子 AWGN。每轴以 0 为判决阈值，等于 0 判为比特 0。
- 输入为非空、偶数长度的二进制序列，最多 10,000 比特；奇数长度报错，不补位。种子范围为无符号 32 位整数，Eb/N0 范围 −10 到 15 dB。
- 独立参数包含比特流、Eb/N0、种子、噪声开关；展示比特数、符号数、误码数、实测 BER、理论 BER 和前 32 位恢复结果。
- SVG 等比例 I/Q 坐标系绘制四个理想点、比特标签、两条判决边界和前 500 个接收符号；错误符号使用不同形状及文字说明。动态对称坐标范围包含所有预览点，不裁剪异常采样；统计使用全部输入比特。
- 星座图提供文字说明和样本数量；增加可展开的前 16 个符号采样表，以文本呈现 I/Q 和判决结果。

数学参考：[MathWorks Phase Modulation](https://www.mathworks.com/help/comm/ug/phase-modulation.html)。理想相干同步、Gray 编码 QPSK 在 AWGN 中的理论比特误码率与 BPSK 相同，可复用现有理论 BER 函数。
