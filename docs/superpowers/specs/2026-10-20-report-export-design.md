# SignalLab 实验报告导出

用户已确认 HTML + Markdown 方案。每个 BPSK、QPSK、BER 实验使用独立导出入口，导出当前数据，不自动调用模型。

- 报告包含实验类型、应用版本、带时区的生成时间、参数和随机种子、实测结果、理论说明、图表及数据表。
- HTML 是自包含文件：样式、SVG 图片全部内嵌，可离线打开，通过浏览器打印为 PDF。Markdown 保留相同内容和内嵌图表，图片显示取决于阅读器的数据 URI 支持。
- BER 报告包含运行时参数快照、逐点误码、理论 BER、区间类型和上下界，未完成扫描明确标为运行中、已取消或失败。未运行与无效参数禁用导出。
- 可选包含已完成 AI 问答及各问题当时的实验快照。默认不包含；正在等待的问答不导出。AI 输出独立标注，不作为实验事实。
- 导出操作同步捕获数据、对话、已渲染图表，形成不可变文档字符串；后续调参不改变已有文件。
- 共享纯格式化模块负责安全转义与 HTML/Markdown；浏览器组件负责 SVG 样式固化、下载和错误提示；现有助教组件复用三个实验的上下文，避免扩大状态提升。

实施顺序：先写格式化测试并观察失败，再实现格式化与图表捕获，接入导出 UI；验证快照一致性、AI 历史、部分扫描、无噪声、转义安全、下载与离线布局，运行测试、构建及 lint 后提交。
